# Screenshots

Place your captures here. README expects:

- `assets/screenshot-light.png` — light theme (`#ffffff/#000000`), D2Coding, window 120×30
- `assets/screenshot-dark.png` — dark theme (`#1e1e1e/#d4d4d4`)
- `assets/demo.gif` — 10s Korean IME typing (`안녕하세요`) + `htop` + theme switch

## How to capture

```bash
# 1. start server
npm run dev
# 2. open http://127.0.0.1:3000, set terminal to 120×30
# 3. macOS: Cmd+Shift+4, Linux: gnome-screenshot -w
# 4. gif: use https://getkap.co/ or `peek` (Linux) or `ffmpeg -f x11grab`
```

Keep images < 1MB. Prefer `png` for screenshots, `gif` < 800px width for README.
