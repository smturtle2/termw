# Code of Conduct

## Our Pledge

We pledge to make participation in termw a harassment-free experience for everyone.

## Standards

Be respectful, constructive, and inclusive. Harassment, discrimination, or personal attacks are not tolerated.

## Enforcement

Report to the maintainers via GitHub issues or email. All complaints will be reviewed and investigated promptly.

We follow the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
